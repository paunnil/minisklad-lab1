# Нотатки викладача — підготовка ЛР №1

Це **повністю працездатний еталон** для викладача. Студентам можна видати **спрощену версію** з частково реалізованою логікою, щоб вони дописали її самостійно.

## Мета ЛР №1

Створення та локальне тестування клієнт-серверного вебзастосунку з REST API, закріплення роботи з масивами, об'єктами, функціями та JSON.

## Орієнтовні навчальні завдання для студентського варіанта

1. Вивчити призначення папок `frontend` і `backend`, перевірити `GET /api/health` та `GET /api/products`.
2. Реалізувати в `frontend/app.js` функцію `calculateTotalValue(items)` — суму `quantity * price` для кожного товару.
3. Реалізувати функцію `countLowStock(items)` — кількість найменувань, для яких `quantity < 5`.
4. Реалізувати/доповнити `POST /api/products` у `backend/server.js`, перевірити дані та додавання до масиву.
5. Перевірити додавання через браузер і через Postman, порівняти JSON-запити та відповіді.

**Рекомендація:** для студентського стартового репозиторію залишити готові HTML/CSS та структуру; у трьох функціональних фрагментах поставити TODO. Окремо створимо цей шаблон після перевірки еталону.

## Важливі демонстрації

- Після додавання нового товару змінюються показники у верхній частині сторінки.
- Якщо кількість товару менша за 5, його позначають як малий залишок.
- Зупинка сервера → API недоступний; після запуску програма повертається до початкових 4 товарів.
- Ресурси HTML/CSS/JS у ЛР №1 віддає Express: додатковий вебсервер не потрібен.

## Архітектурні рішення, щоб спростити наступні ЛР

- `frontend` і `backend` розташовані в окремих папках: для ЛР №2 не потрібно реорганізовувати проєкт.
- `frontend/config.js` відокремлює базову адресу API від реалізації клієнта.
- `frontend/demo-data.js` підтримує статичний режим Cloudflare Pages до появи Worker (ЛР №3).
- `photoUrl: null` передбачає фотографії товарів у ЛР №8.
- `GET /api/products` і `POST /api/products` використовують JSON; у ЛР №5–6 масив заміниться D1.

## Перевірка працездатності

Після `npm install` та `npm start`:

- [ ] Відкривається `http://localhost:3000`.
- [ ] Показано 4 товари й розраховані показники.
- [ ] Пошук за назвою працює.
- [ ] Фільтр малого залишку залишає «Клавіатура» і «Вебкамера».
- [ ] Додавання товару працює, API повертає HTTP 201.
- [ ] Некоректний товар (кількість -1) через Postman повертає HTTP 400.
- [ ] Після перезапуску сервера відновлюються початкові дані.
